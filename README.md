# ownership-and-boards

**Who gets a seat on the board?** How combinations of owners (business groups, families, pension
funds, institutional and foreign investors, the State) translate into board seats in two markets
with concentrated ownership: Chile and Spain.

Work in progress. The first step checks which public sources can be downloaded in a structured
way: the CMF (Chile) company filings and the CNMV (Spain) annual corporate governance reports.

- `src/boards/probe.py`: cheap probes of each source, run by the `Probe` workflow.
- Results: annotations on each run, raw samples on the `probe-results` branch.
